使用方法
1. 用现代浏览器打开 index.html。所有资源均为相对路径，无需构建或联网加载依赖。
2. 也可将整个项目文件夹交给任意静态 HTTP 服务运行。
3. 移动鼠标产生平滑视差，悬停玩偶略微放大，点击或轻触玩偶连续 Q 弹两次。键盘 Tab 选中后可按 Enter 或空格触发。
4. 手机支持 Pointer Events；在系统偏好减少动态效果时降低运动幅度并关闭持续漂浮和视差。小于 640px 高度的手机可正常纵向滚动。
